# Simple Calculator in C

This is a beginner-friendly calculator project developed using the C programming language.

## Features
- Addition, subtraction, multiplication, and division
- Perform all arithmetic operations at once
- Choose a specific arithmetic operation
- Continuous calculations with multiple numbers
- Menu-driven interface
- Exit option

## Concepts Used
- C programming fundamentals
- Variables and data types
- If-else statements
- Switch-case statements
- While loops
- User input using scanf()

## About This Project
I created this project to practice my C programming skills and improve my understanding of conditional statements, loops, and basic programming logic.

## How to Run
1. Download the source code.
2. Compile it using a C compiler such as GCC.
3. Run the compiled program.
